Percentiles use the active subset. Changing size, dates, additions, or exclusions recalculates the forecast immediately.
Outliers are manually controlled. Use the exclude action in the table to remove a point from calculations, then restore all when needed.
Added rows stay local. The dashboard keeps your manual edits in browser storage. It does not write back to the Excel file.
